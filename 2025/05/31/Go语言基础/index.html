init 初始化

本实验：理解 Go 中的初始化过程，包括 init() 函数的使用和程序启动时的顺序。

在 Go 语言中，Init 函数会在包初始化时运行，也就是在所有程序代码运行之前运行并只运行一次，init()

函数的执行顺序与导入顺序有关。在 main 包中引入了 a 和 b 包，导致它们的 init() 函数先被调用，又因

为 a 包中又引入了 b 包，故 b 包的 init() 函数昀先执行，其次是 a 包的，昀后是 main 包中的。

指针：

理解指针的概念和用法，在 Go 中如何使用指针操作数据。

指针和值传递的区别。通过指针传递，可以直接修改变量的值，而通过值传递，会创建一个变量的副本，对副本的修改不会影响原始变量。

切片

学习切片 (slice)，Go 中灵活且强大的数据结构之一，用于处理序列数据。

下面是一个数组例子，数组是一个相同类型且长度固定连续内存片段，以编号访问每个元素，编号是不能越界的。

myArray := [5]int{1, 2, 3, 4, 5}

切片则是对数组一个连续片段的引用，数组定义中不指定长度即为切片，切片在未初始化之前默认为nil（无）， 长度为0。切片可以灵活的添加元素或者删除元素。

makenew：通过 make 或者 new 构造一个切片，New 返回指针地址，Make 返回第一个元素，可预设内存空间，避免未来的内存拷贝。

forrange：修改切片的值常出现的BUG，核心原因是GO全都是值传递。
